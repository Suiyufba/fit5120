# Known Limitations

This document is important — especially for a safety-related project. Be transparent about what the system can and cannot do.

## Data Freshness

- Hazard data is polled every 2 hours from upstream providers (VicEmergency, OpenWeather, DataVic).
- Real-time changes (e.g., a new bushfire) may take up to 2 hours to appear.
- The API returns `isStale: true` when data exceeds the freshness threshold (10 minutes).
- **Do not rely on this application as your sole source of emergency information.**

## Hazard Coverage

- Only Victoria, Australia is covered.
- Hazard layers: fire, flood, storm, heat, trail, other.
- Not all hazard types are available from all providers (e.g., VicEmergency focuses on fire/flood).
- Community reports expire after 24 hours.

## Route Planning

- Route suggestions are algorithmically generated — they are not official safety advice.
- The risk model uses distance-based hazard proximity, terrain difficulty, and user experience level.
- Route timing estimates assume average hiking speeds and do not account for individual fitness.
- No-go recommendations are conservative but not guaranteed to catch every danger.
- **Always check official sources (VicEmergency, BOM, Parks Victoria) before hiking.**

## AI Narration

- Route narration is generated by Google Gemini (gemini-2.5-flash-lite).
- AI-generated text may contain inaccuracies or hallucinations.
- Narration is meant as an explanatory aid — not a substitute for professional guidance.
- The AI service may be unavailable during peak usage or API outages.

## Authentication

- Password reset uses security questions (not email tokens). This is weaker than email-based reset.
- Rate limiting is applied to auth endpoints (8 requests per 15 minutes).
- JWT tokens expire after 7 days by default.

## Database

- When `DATABASE_URL` is not configured, the backend falls back to in-memory storage.
- In-memory data is lost on server restart.
- Community report images up to 512KB are stored as base64 in the database.

## Map Rendering

- Mapbox GL JS requires a valid access token (`VITE_MAPBOX_ACCESS_TOKEN`).
- Without the token, the 3D terrain route view degrades to a message.
- Leaflet is used as a fallback map engine on some pages (Risk Map, Community Reports).

## Browser Support

- Tested on modern Chromium-based browsers and Safari.
- Mobile support is functional but some map interactions may be less smooth on older devices.
- Geolocation requires HTTPS in production (except localhost).

## Scale

- Designed as a prototype/MVP — not production-hardened for high traffic.
- No horizontal scaling, no CDN for map tiles, no distributed caching.
- PostgreSQL connection pool is not tuned for concurrent load.

## Security

- Helmet.js provides baseline HTTP security headers.
- CORS is restricted to configured origins.
- No CSP reporting, no audit logging, no intrusion detection.
- Dependencies are not automatically scanned for vulnerabilities.
