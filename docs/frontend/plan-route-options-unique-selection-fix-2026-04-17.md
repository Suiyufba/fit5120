# Plan Route 选项重复高亮修复（2026-04-17）

## 问题
- 在 `Plan Route` 三档路线卡片中，存在同一条路线被分配到两个卡片的情况，导致：
  - 两个卡片同时高亮
  - 地图上看起来只有两条有效路线
- 同时用户希望卡片难度标签显示英文。

## 修复
- 文件：`frontend/src/views/RoutePlanner.vue`
  - 三档路线分配逻辑改为“按卡片目标难度匹配 + 严格唯一 id 去重”。
  - 禁止同一 `route.id` 占用多个卡片位，保证单选高亮正确。
  - 难度标签统一改为英文：`Easy / Moderate / Hard`。

## 结果
- 卡片只会有一个激活态。
- 路线卡片与地图路线对应关系更稳定。
