# 🌿 EcoQuiz Australia

> 让环保知识变得有趣，让行动变得简单

一个面向澳大利亚用户的环保问答网站，通过答题赚取积分，参与线下环保活动。

## ✨ 功能特色

- **每日问答** - 答题赚积分，连续学习有奖励
- **活动中心** - 报名参加海滩清洁、植树等环保活动
- **积分商城** - 用积分兑换环保奖励
- **排行榜** - 与好友比拼环保知识

## 🌏 澳洲本土化

- 本土环保知识（考拉保护、大堡礁、丛林防火）
- 按州/领地筛选活动
- 南半球季节适配

## 🛠️ 技术栈

- Frontend: React + Tailwind CSS
- Backend: Node.js (规划中)
- Database: PostgreSQL (规划中)

## 📁 项目结构

```
eco-quiz-australia/
├── DESIGN.md          # 设计文档
├── src/               # 源代码
│   ├── components/    # 组件
│   ├── pages/         # 页面
│   └── styles/        # 样式
└── public/            # 静态资源
```

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```
